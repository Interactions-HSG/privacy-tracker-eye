About this site

Nimbus Market does not exist. This is a research fixture: a fictional shop used in a university study on how people perceive online tracking, and a test bench for the Tracker Eye browser extension.

What happens to what you type

  • Nothing is submitted. The forms never POST or GET anywhere. Pressing “Continue” only moves to the next page (see assets/next.js); what you typed disappears with the page.
  • Nothing is stored. No cookies, no local storage, no server — the pages are static files served from the researcher's own machine.
  • The tracking beacons carry field names, never values. The page fires pixels to real advertising and analytics domains (google-analytics.com, amazon-adsystem.com, …) carrying the page name, the event, the name of the field you are in and how many characters it holds — the same shape of data a real shop leaks. The requests fail, because no such endpoint exists; the point is only that a tracker-aware extension can observe the attempt. The code is in assets/mock-tracking.js and can be read in full.

What the Tracker Eye extension does here

If the study's browser extension is installed, it observes those requests the way it observes any site, and shows an eye whose attention reflects how heavily the page is being tracked. When you start filling in a field, the eye flies over and reads along. The extension records the kind of field (name, e-mail, birthday…) and how many characters it holds — never the characters themselves — so the researchers can compare what people actually disclosed with what they remember disclosing.
